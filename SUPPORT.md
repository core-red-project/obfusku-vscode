# Support

## Getting Help

**GitHub Issues**
For bugs or unexpected behavior, open an [issue](https://github.com/core-red-project/obfusku-vscode/issues). Use the bug report template and include enough context to reproduce the problem.

**Discord**
For questions, general discussion, or anything that isn't a bug — join the Sxnnyside Project community at [discord.gg/WnAvUHTnG](https://discord.gg/WnAvUHTnG).

## Before Asking

- Check the [README](README.md) — installation, commands, and settings are documented there.
- Search existing [issues](https://github.com/core-red-project/obfusku-vscode/issues) before opening a new one.
